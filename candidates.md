# Automation Candidates

Ranked candidates for internal MSP developer tooling, derived from observed Claude Code
session behavior. Generated by `automation-spotter/`; see
`docs/superpowers/specs/2026-08-25-automation-spotter-design.md` for how the data is
produced and redacted.

**`Status` is human-owned.** The spotter updates counts and timings on re-run and never
touches this column. Set it to `building`, `built`, or `rejected` as you triage.

**`Distinct projects` is a count, never engagement names.** No motif below is
client-specific: every row spans two or more distinct engagements, which is what makes it
safe to describe in prose at all.
